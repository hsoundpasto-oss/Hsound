Descripción

HSound es una aplicación móvil desarrollada en Flutter que conecta artistas musicales de Pasto, Nariño con su comunidad. La plataforma permite a los artistas publicar sus canciones mediante enlaces de YouTube, Spotify y SoundCloud, mientras que los oyentes pueden descubrir música local, buscar por género y guardar sus canciones favoritas. Cuenta con un panel web administrativo para la gestión de usuarios y contenido. El proyecto se desarrolla con fines académicos como trabajo de grado.

Tecnologías

Frontend: Flutter (Dart)
Backend: Firebase (Firestore, Authentication, Storage, Hosting)
APIs: YouTube, Spotify, SoundCloud
Panel Admin: Flutter Web

Funcionalidades

Registro e inicio de sesión con email y Google
Reproducción de música desde plataformas externas
Búsqueda avanzada con filtros por género y popularidad
Sistema de favoritos en tiempo real
Perfil de artista con biografía y enlaces a redes sociales
Publicación de canciones mediante enlaces externos
Panel web para administradores
